## ¿Qué es Appium?

Web Oficial de Appium: [http://appium.io/](http://appium.io/)

Repositorio de GitHub: [https://github.com/appium/appium](https://github.com/appium/appium)![](/img/blog-images/old-post/2019/02/appium-and-perfecto.png?w=300)

Appium es el estándar en automatización de pruebas para móviles. Se trata de un framework **Open Source** que permite probar aplicaciones móviles **nativas o híbridas** en las plataformas móviles **iOS y Android**.  Es una herramienta _cross-platform_, es decir, un framework que sirve para varias plataformas a la vez, con lo cual, podemos crear pruebas en diferentes plataformas utilizando la misma API de Appium. Esto también nos permite reutilizar el código de pruebas que desarrollamos para una aplicación que está en varias plataformas.

Appium utiliza el _WebDriver_ de [Selenium](https://www.seleniumhq.org/), que es un entorno de pruebas para aplicaciones web y que especifica un protocolo cliente-servidor conocido como **_JSON Wire Protocol_.** Esto permite al cliente el uso de marcos de pruebas escritos en cualquier lenguaje, enviando las solicitudes HTTP al servidor. Es por eso que se dice de Appium que es _"como Selenium, pero para aplicaciones móviles"._

## ¿Qué ventajas tiene Appium?

La característica principal es que Appium sirve tanto para iOS como para Android y puedes crear test para ambas plataformas de forma bastante sencilla.

Otra de las características es que podemos elegir el lenguaje con el que nos sintamos más cómodos para programar los test, ahora mismo los lenguajes soportados son: _Java, Objective-C, JavaScript con Node.js, PHP, Python, Ruby, C#, Clojure, o Perl._

## ¿Por qué elegir Appium?

Principalmente,  Appium es una herramienta que tiene un grado de madurez alto, y apunta a ser el estándar para pruebas en dispositivos móviles de los próximos años. Además, es fácil de aprender, funciona para las plataformas principales de movilidad (iOS y Android) y tiene un gran apoyo de la comunidad.
